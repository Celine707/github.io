# HC 时尚艺术｜Fashion Art Portfolio

欢迎来到我的作品与教学分享空间。

这里用于展示我的时装画 / 设计概念作品，并作为教学素材库，方便学生学习与交流。

## 你可以在这里看到什么？

- **时装画作品集**：按系列 / 主题整理的作品展示  
- **创作思路与过程**：灵感、构图、结构、材质表达等  
- **教学示范**：课堂讲解要点、练习方向、案例拆解（持续更新）  
- **实验性内容**：AI 设计探索、跨文化风格融合、实验性视觉语言


## 给学生的话（Student Notes）

同学们可以把这里当作：
- 作品参考库（画面语言、比例、节奏、系列化表达）
- 灵感索引（主题、文化元素、廓形与细节）
- 学习路径（从“会画”到“会表达”，再到“会做系列”）

如果你想用某个作品作为练习，请注明来源并保持尊重与学术诚信。
